Recovering a Missed Journey Audience

An import error left some members out of a live customer journey. I recommended a one-time send to the people it missed, secured the client’s approval and worked with developers on how future records should enter.

The missed audienceThe recovery decisionFuture entries

Who still needed the message?

The journey was already in use. The import error meant that some intended recipients had never entered it. Changing how the next import ran would address future entries, but the client still needed a decision about the group whose communication was already due.

A one-time send for the missed group

I worked through the recovery options with the client and developers. My recommendation was to handle the missed group separately. That gave the client a specific audience and a defined action to approve while the developers and I planned the routing change.

Future entries needed a routing change

The data extension is the table Marketing Cloud uses for these records. The longer-term plan changed where the incoming records landed and how SQL routed them into the journey. I coordinated that plan alongside the recovery approval so the client could deal with the immediate audience and the entry problem separately.
