What this model leaves to production.


The event ledger exists only during one evaluation. The model does not implement a durable queue, cross-run deduplication, message delivery, device identity, warehouse integration, production throughput or a live vendor response contract. Separate mock-adapter tests exercise bounded retries and partial responses.


The business journey key is customer ID plus search ID. A transport batch ID is not a deduplication key. Identity resolution never grants consent from an anonymous profile and preserves an equally recent or newer opt-out.


Before a real release, specialists would validate platform identity semantics, source authority, scheduling, persistent idempotency, channel eligibility, cooldowns, monitoring and recovery. Read the broader architecture and rollout rationale →
